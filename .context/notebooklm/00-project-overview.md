## Non-negotiable rules (from `CLAUDE.md`, summarized)

1. One source of truth for professional content; both renderers consume it.
2. Mode (`classic` | `rogue`) is UI state; active section is domain state; switching mode
   preserves the active section.
3. Sections are deep-linkable by stable hash id (`#projects`); no mode-specific routes.
4. Never mount both renderers' expensive runtime simultaneously.
5. Three.js / R3F never ship in the critical bundle.
6. Drag is never the only way to open a card — click, keyboard and tap always work.
